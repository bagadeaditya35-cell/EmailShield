# Choosing a licence (decision needed from the maintainer)
No LICENSE file is included on purpose: without one, the code is "all rights reserved" and others may not legally reuse it. Decide before publishing:
- **Who owns the work?** If any part was created as part of employment, an internship, a college project or the PCMC Cyber Cell, check the institution's IP policy first.
- **Permissive (MIT / Apache-2.0)**: maximum reuse; Apache-2.0 adds a patent grant and notice requirements. **Copyleft (GPL-3.0 / AGPL-3.0)**: derivatives must stay open; AGPL covers network services. **No licence / source-available**: portfolio viewing only.
- Third-party components keep their own licences (FastAPI, uvicorn, pywebview, PyInstaller, Inno Setup: see their terms; MITRE ATT&CK use requires the ATT&CK terms/attribution).
Add the chosen file as `LICENSE` and mention it in README. This is not legal advice.
